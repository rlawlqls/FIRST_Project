url은 서버의 별명 정도
rest api를 이용해서 웹 브라우저를 요청하게 됨

웹 서버 - 브러우저에 HTML, CSS, JS를 전달한다.
 내 웹 브라우저에 저런 걸 보내준다. 
 보내주는 방식 : Nginx, Apache HTTP Server 와 같은 정적 파일 제공

API : 기능을 제공해주는 서버다.
 동적인 기능을 해줌
 외부 서버와 지속적으로 연결을 하면서 동적으로 불러옴
 key value 형태로 되어있음 
 { "title" : "모집 안내" }
 client가 정보를 요청해 (예를 들면 삼성 정보 주가)
 > { " 회사 " : "삼성전자" 
        "주가 " : 270,000 
     }

서버는 기능에 따라 다양함

javaScript는 정적이라서 상호작용할 수 있음. 이걸 통해서 상호작용한다.
